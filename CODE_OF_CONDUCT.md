# Code of Conduct

## Our Commitment

We want this project to be a respectful, constructive space for learning and collaboration. Participants are expected to communicate with care and help keep discussions welcoming to people with different backgrounds and levels of experience.

## Expected Behavior

- Be respectful, patient, and constructive in discussions and reviews.
- Critique ideas and code, not people.
- Accept responsibility for mistakes and corrections.
- Respect privacy and do not publish another person's personal information.
- Keep contributions relevant to the project and its educational purpose.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, intimidation, unwanted sexual attention, doxxing, and disruptive or bad-faith conduct are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions, close discussions, or restrict participation when this Code of Conduct is violated. Report concerns privately to the repository maintainers through GitHub; do not use a public issue for sensitive reports.

This Code of Conduct applies in project spaces and whenever someone is officially representing the project.
